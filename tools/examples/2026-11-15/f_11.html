공용 부품(components/ui)은 두고, 쓰는 쪽(components/common)만 바꿨다

속성을 맞춘 게 아니라 경로를 없앴다

전: 버튼 안에 링크를 끼워 넣기
경로
PaginationLink → Base UI Button → render={<a>} → 버튼 속성 + 링크 속성 병합
<Button render={<a href="/posts?page=1" />} nativeButton={false}> 이전 </Button>
서버와 브라우저가 tabIndex를 다르게 계산했다.
비활성 "이전"도 Tab에 잡히는 가짜 링크가 됐다.
후: 링크는 링크, 비활성은 span
경로
이동 가능 → Next.js Link + 버튼 스타일(buttonVariants)
이동 불가 → <span aria-disabled="true">
<Link href="/posts?page=2" className={buttonVariants({variant:"ghost"})}> 다음 </Link> <span aria-disabled="true" className={...}>이전</span>
병합 경로를 아예 쓰지 않는다. span은 애초에 Tab 대상이
아니라 "눌러도 아무 일 없는 링크"가 사라졌다.
Base UI 문서도 같은 말을 한다: "링크는 자체 의미가 있으니 render로 버튼처럼 만들지 말고, 버튼처럼 보이게 하려면 <a>에 CSS를 입혀라"
