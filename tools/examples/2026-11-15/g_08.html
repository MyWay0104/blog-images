새 환경변수를 추가할 때마다 거치는 한 가지 질문

접두사를 정하는 기준은 하나다

이 값이 브라우저에 보여도 되는가?브라우저로 간 값은 누구나 개발자 도구에서 꺼내 볼 수 있다
예
아니오
NEXT_PUBLIC_ 를 붙인다
사이트 주소, 공개 분석 ID처럼 어차피 공개된 값
빌드 때 번들에 박히니, 환경마다 값이 다르면 빌드 시점에 맞게 넣는다
코드에서는 process.env.NEXT_PUBLIC_이름 그대로 써야 인라인된다 (변수로 돌려 읽으면 안 됨)
접두사 없이 서버에만 둔다
토큰, API 키, 캐시 갱신 비밀번호처럼 새어 나가면 안 되는 값
Route Handler · Server Component · Server Action에서만 읽는다
Vercel에는 Secret 타입으로 등록 (저장 뒤 값을 다시 볼 수 없음)
헷갈리면 "아니오" 쪽에 둔다. 서버에만 있는 값을 나중에 공개하는 건 쉽지만, 한 번 번들에 실린 값은 되돌릴 수 없다
