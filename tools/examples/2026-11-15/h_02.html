api-sdk-lab — 로컬 Ollama의 같은 모델을 세 가지 방식으로 호출

셋 다 결국 같은 주소로 간다

1단계 API 직접 호출
requests
requests.post( "http://…:11434/v1/chat/ completions", headers=…, json=payload) r.json()["choices"][0] ["message"]["content"]
주소·헤더·본문·응답 경로를 전부 내가 쓴다. 가장 투명하고, 가장 번거롭다
2단계 SDK
openai
client = OpenAI( base_url="http://…/v1/", api_key="ollama") client.chat.completions .create(model=…, messages=…) response.choices[0] .message.content
주소는 한 번만 설정. 오류는 SDK가 예외로 던져 준다. 내부는 안 보인다
3단계 LangChain
langchain-openai
llm = ChatOpenAI( model=…, base_url="http://…/v1/") response = llm.invoke(prompt) response.content
제공자를 바꿀 때 클래스만 교체. 한 겹 더 쌓여 더 안 보인다
세 파일의 최종 목적지
POST http://localhost:11434/v1/chat/completions
SDK도 LangChain도 마법이 아니라, 내부에서 1단계와 똑같은 HTTP 요청을 만들어 보낼 뿐이다 — 감춰 주는 것은 일의 내용이 아니라 일의 번거로움이다
