세 호출의 시간표

updateTag('posts')
즉시 만료. 쓴 사람이 바로 본다. Server Action 안에서만
저장 → updateTag

revalidateTag('posts', 'max')
오래됐다고 표시. 옛것을 주면서 뒤에서 갱신. Server Action·Route Handler 모두 가능
저장 → revalidateTag

그 다음 요청
옛 결과
옛 결과를 즉시 주고, 뒤에서 새로 만든다
새 글이 보인다
revalidateTag('posts', {expire: 0})
옛것을 주지 않음. updateTag를 못 쓰는 웹훅·Route Handler에서 즉시 비울 때
웹훅 → revalidateTag
다음 요청
옛 결과
새로 읽는 동안 기다림
새 글이 보인다
공식 문서: 갱신은 revalidateTag 호출이 아니라 요청이 촉발한다 — 태그를 쓰는 페이지는 방문될 때 갱신된다.
인자 하나짜리 revalidateTag(tag)는 deprecated이며 {expire: 0}처럼 동작한다
