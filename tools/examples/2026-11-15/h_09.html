LangChain의 이점이 드러나는 지점 — 제공자를 바꿀 때

클래스 하나만 바뀌고, 나머지 줄은 그대로

Ollama (OpenAI 호환 서버)
from langchain_openai import ChatOpenAI llm = ChatOpenAI( model="llama3.2", base_url="http://localhost:11434/v1/", api_key="ollama", # 필요하지만 무시됨 ) response = llm.invoke(prompt) print(response.content)
Ollama가 OpenAI와 같은 모양의 엔드포인트를 내주기 때문에 "OpenAI"라는 이름의 클래스로 로컬 모델을 부른다
Anthropic Claude로 바꾸면
from langchain_anthropic import ChatAnthropic llm = ChatAnthropic( model="claude-…", api_key="…", # 코드에 넣지 말 것 ) response = llm.invoke(prompt) print(response.content)
요청·응답 형식이 OpenAI와 달라 전용 패키지가 필요하지만, invoke와 .content 줄은 그대로다. 1단계였다면 URL·헤더·JSON 구조를 전부 다시 써야 한다
설치 이름은 하이픈(langchain-openai), import 이름은 밑줄(langchain_openai) — 파이썬 식별자에 하이픈을 쓸 수 없어서다
