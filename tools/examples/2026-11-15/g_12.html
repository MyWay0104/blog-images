Next.js 환경변수 — 공식 문서로 확인한 네 가지

접두사 하나에 걸린 네 가지 사실

1
기본은 서버 전용
"기본적으로 환경변수는 서버에서만 쓸 수 있다." 브라우저로 보내려면 NEXT_PUBLIC_을 붙여야 한다.
Next.js 문서: Runtime Environment Variables
2
빌드 때 값이 박힌다
NEXT_PUBLIC_ 값은 next build 때 JS 번들에 인라인된다. 빌드 뒤에는 환경변수를 바꿔도 반응하지 않는다. process.env[변수명]처럼 돌려 읽으면 인라인되지 않는다.
Next.js 문서: Bundling Environment Variables for the Browser
3
읽는 순서와 NODE_ENV
process.env → .env.$(NODE_ENV).local → .env.local → .env.$(NODE_ENV) → .env 순서로 찾고 먼저 찾으면 멈춘다. NODE_ENV는 next dev면 development, 그 외 production으로 자동 지정.
Next.js 문서: Load Order · Good to know
4
배포 서비스의 Secret 타입
Vercel은 Config(저장 뒤에도 읽힘)와 Secret(저장 뒤 쓰기 전용)으로 나눈다. 토큰·API 키는 Secret. 32자 이상 값은 빌드 로그에서도 [REDACTED]로 가린다.
Vercel 문서: Config and Secret environment variables
환경변수는 값 저장소이자 보안 경계다 — NEXT_PUBLIC_은 "브라우저에 전달될 수 있다"는 선언이다
