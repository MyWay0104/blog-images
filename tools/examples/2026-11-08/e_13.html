외부 npm 도구를 처음 쓰기 전에 — 공식 문서 기준

설치 전 확인 4가지

1
명령 형태
내가 치려는 첫 단어가 정말 그 도구의 이름인가?
npx는 첫 위치 인자를 패키지 이름으로 읽는다. 순서가 바뀌면 다른 패키지를 찾는다. 옵션은 패키지 이름 앞에 쓴다.
2
이름과 버전
그 이름의 패키지는 무엇이고 몇 버전까지 있나?
npm view <도구> description version versions — 레지스트리 정보를 읽기만 한다. 설명이 내가 아는 도구와 다르면 멈춘다.
3
설치 스크립트
설치하는 순간 자동으로 도는 명령이 있나?
npm view <도구> scripts 에 preinstall · install · postinstall이 있으면 내용을 읽는다. npm 문서도 "거의 필요 없는 스크립트"라고 적는다.
4
버전 고정
다음에 실행할 때도 같은 코드가 도는가?
npx <도구>@<버전> 처럼 검토한 버전을 적는다. 버전이 없으면 매번 latest를 받고, 프로젝트에 저장할 때 기본은 ^ 범위다.
넷 다 "설치하기 전에, 읽기만 하는" 확인이다 — 프록시가 대신 해 주지 않는 부분
