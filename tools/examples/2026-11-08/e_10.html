reading-notes — 외부 npm 도구를 처음 쓰기 전에 치는 명령 (공식 문서의 명령 형식을 바탕으로 재구성)
# 1) 명령 형태부터 확인: 첫 단어가 패키지 이름이다 (정확한 형태는 도구의 README에서) # npx install <도구> (X) → npx <도구> install (O) # 2) 그 이름의 패키지가 무엇인지, 몇 버전인지 — 읽기만 한다, 설치하지 않는다 > npm view <도구> name description version > npm view <도구> versions # 지금까지 나온 버전 목록 # 3) 설치할 때 자동으로 도는 스크립트가 있는지, npx가 실행할 파일은 무엇인지 > npm view <도구> scripts # preinstall·install·postinstall 이 보이면 멈춘다 > npm view <도구> bin # 4) 검토한 버전으로 고정해서 실행한다 (버전을 안 적으면 그때그때 latest) > npx <도구>@<검토한 버전> install > npx --ignore-scripts <도구>@<검토한 버전> install # ↑ 설치 스크립트를 돌리지 않고 시험할 때. 옵션은 패키지 이름 앞에 쓴다 (npx 규칙)
