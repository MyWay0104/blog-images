공식 문서(modelcontextprotocol.io · a2a-protocol.org) 기준

상대가 누구냐로 가르는 비교표

항목MCP (도구를 붙인다)앱 안 서브에이전트 (내 것을 나눈다)A2A (남의 에이전트를 부른다)
상대도구·자료·프롬프트 템플릿을 내주는 서버내가 만든 또 하나의 에이전트다른 팀·조직이 운영하는 에이전트
상대의 속입력 스키마·설명을 공개 (tools/list)전부 내 것안 보임. 선언된 능력(Agent Card)만
상태대개 상태 없는 함수 호출내 앱의 컨텍스트 안긴 작업·여러 턴 대화를 상대가 유지
모델·프롬프트·권한내 에이전트가 판단, 도구는 실행만내가 정한다그쪽이 정한다. 나는 바꿀 수 없다
장애가 나면도구 호출 실패를 내 에이전트가 처리내 코드 문제상대 에이전트의 문제. 나는 재시도·대체만
규격JSON-RPC 2.0, stdio / Streamable HTTP규격 아님. LangGraph·ADK 같은 프레임워크 기능HTTP · JSON-RPC · SSE 위의 프로토콜
문서의 한 줄"MCP connects each agent to its own tools"(A2A 문서의 agent stack: 프레임워크는 에이전트를 만드는 도구 모음)"A2A connects the agents to each other"
