Claude Code — 답변 형식 (예시)
## 확인된 사실 1. 진입점: app/main.py:ask() — 질문 문자열을 받는다 2. 스키마 수집: app/schema.py:load_tables() — information_schema를 조회 3. 후보 선택: app/select.py:pick_tables() — 질문과 테이블 설명을 비교 4. 프롬프트 주입: app/prompt.py:build() — 고른 스키마를 템플릿에 삽입 5. SQL 생성·실행: app/run.py:execute() — 결과를 표로 반환 ## 코드에 없어서 모르는 것 - 분석용 DB에 테이블이 어떻게 적재됐는지 (이 저장소에 적재 코드 없음 → 출처 불명) - 테이블 설명문을 누가 작성했는지 (파일만 있고 생성 과정 없음) - 후보 선택의 유사도 임계값이 어디서 정해지는지 (상수 없음, 설정 파일 미발견)
