Playwright MCP가 읽는 것

HTML → DOM → 접근성 트리 → 스냅샷

① 파일
HTML
서버가 보내 준
글자 그대로
<input id="q">
브라우저가 만든다
▶
② 메모리
DOM
파싱해서 만든
트리 전체
div·label·input
브라우저가 만든다
▶
③ 파생본
접근성 트리
의미만 남긴 요약
role·name·state
textbox "검색"
브라우저가 만든다
▶
④ LLM에 전달
스냅샷
트리를 텍스트로
+ ref 번호
[ref=e5]
MCP가 만든다
LLM이 받는 것은 ④뿐이다. DOM(②)을 직접 읽는 게 아니라 파생본을 읽는다.
