가상환경을 "활성화"하는 것과 "그 파이썬으로 실행"하는 것은 다른 일

venv를 쓰는 길은 두 개다

① 활성화하고 실행
activate 스크립트를 먼저 돌린다
1
.venv\Scripts\Activate.ps1 실행
2
PATH 맨 앞에 .venv\Scripts가 끼어든다
3
VIRTUAL_ENV가 채워지고, 프롬프트에 (.venv)가 붙는다
4
이제 python 01_api_direct.py
② 경로로 직접 실행
venv 안의 python을 바로 부른다
1
활성화 스크립트를 돌리지 않는다
2
.venv\Scripts\python.exe를 전체 경로로 지정해 실행
3
PATH, VIRTUAL_ENV, 프롬프트는 그대로
4
제 기록에서 VS Code의 Ctrl+F5가 쓴 방식
▼   ▼
둘 다 같은 인터프리터  .venv\Scripts\python.exe  → 같은 패키지
표시(프롬프트의 (.venv), VIRTUAL_ENV)는 ①에서만 생긴다. 그래서 ②는 "활성화가 안 된 것처럼" 보이지만 실행은 venv로 된다
