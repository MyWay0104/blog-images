"(.venv)가 안 떠요"에서 멈추지 않고 실제 파이썬을 확인하는 순서

불안하면 이 세 가지를 본다

1
VS Code 오른쪽 아래 상태 표시줄
지금 선택된 인터프리터가 .venv로 표시되는지 본다. 다르면 표시줄을 누르거나 Python: Select Interpreter로 고른다.
2
실행 파일 맨 위에 두 줄
출력된 경로 안에 .venv가 들어 있으면 그 가상환경의 파이썬으로 돈 것이다.
import sys print(sys.executable) # ...\api-sdk-lab\.venv\Scripts\python.exe
3
더 확실하게는 판별식 한 줄
공식 문서가 "이것만 확인하면 충분하다"고 적은 식이다. True면 가상환경 안이다.
print(sys.prefix != sys.base_prefix) # True
프롬프트의 (.venv)와 VIRTUAL_ENV는 판별 기준으로 쓰지 않는다 — 비어 있어도 가상환경일 수 있다
