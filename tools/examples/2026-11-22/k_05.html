api-sdk-lab — 같은 파일을 두 가지 파이썬으로 실행 (샌드박스 리눅스, 실제 실행)
# ① 가상환경과 상관없는 시스템 파이썬 $ python3 01_api_direct.py 실행한 파이썬 : /usr/local/bin/python3 sys.prefix : /usr/local base_prefix : /usr/local venv 안인가 : False VIRTUAL_ENV : None # ② 활성화하지 않고, venv 안의 python을 경로로 직접 지정 $ .venv/bin/python 01_api_direct.py 실행한 파이썬 : /work/api-sdk-lab/.venv/bin/python sys.prefix : /work/api-sdk-lab/.venv base_prefix : /usr/local venv 안인가 : True VIRTUAL_ENV : None ← 표시는 비어 있는데 venv로 돌았다
