embedding-demo — 모양만 확인하는 장난감 예시 (샌드박스 실제 실행, 진짜 모델 아님)
$ python3 embedding_shapes.py 문장 A의 ID : [0, 1, 3] ← 토크나이저의 결과는 정수 목록 문장 B의 ID : [0, 2, 4] 토큰 임베딩 모양 : (3, 4) ← 토큰 3개 x 4차원 = 벡터가 3개 A의 '배' 벡터 : [ 0.13 -0.13 0.64 0.1 ] B의 '배' 벡터 : [ 0.13 -0.13 0.64 0.1 ] 두 '배'가 같은가 : True ← 문맥이 달라도 표에서 꺼낸 값은 같다 문장 벡터 모양 : (4,) ← 합치면 벡터가 1개
