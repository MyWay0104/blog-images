Jev와 LLM structured output을 가르는 네 가지

배선은 그대로, 부품을 고른다

층이 다르다
LangGraph는 보내는 배선이고, Jev는 라우팅 노드 안에서 정하는 부품이다. 비교 상대는 그 자리의 LLM structured output이다.
LangGraph 문서: Routing 예제의 with_structured_output
형식은 둘 다 지킨다
LLM의 structured output도 스키마를 따르고 열거형 값이 제한된다. 형식 보장은 Jev만의 장점이 아니다.
OpenAI 문서: Structured Outputs
갈리는 것은 확률이다
Jev는 고른 값과 함께 선택지마다의 확률을 준다. 애매한 건을 코드가 알아보고 되묻거나 넘길 수 있다.
TypeSafe 문서의 응답 기록: returns 0.61 / billing 0.35, confidence 0.42
싼 것부터 쓴다
코드 · 버튼 → 판정 모델 → LLM · 사람. 판정 모델은 글을 쓰지 못하므로 LLM을 없애지 않고, LLM까지 가는 건수를 줄인다.
